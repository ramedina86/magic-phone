A SMALL, OPEN INTERFACE

Notes, from anywhere
on your network.

Use the same host as this page. All responses are JSON except a successful deletion, which has no body. Notes are stored persistently on this Pi. There are no titles or formatting fields.

Access: this is a shared LAN service with no login. Anyone who can reach it can read and change notes. Cross-origin browser writes are rejected; command-line clients can use the API directly.

MethodPathAction
GET/api/notesList notes, newest first
POST/api/notesCreate a note
PATCH/api/notes/{id}Set or remove a highlight
DELETE/api/notes/{id}Delete a note permanently

Create a note

curl -X POST http://rmpizero2w.local/api/notes \
  -H 'Content-Type: application/json' \
  -d '{"text":"Remember the little things.","highlighted":false}'

Returns 201 Created with the saved note. text is required: 1–20,000 Unicode characters, not only whitespace. Line breaks are preserved. highlighted is optional and defaults to false. Extra fields are rejected.

{
  "id": 1,
  "text": "Remember the little things.",
  "highlighted": false,
  "created_at": "2026-11-16T12:00:00.000000+00:00"
}

Read notes

curl 'http://rmpizero2w.local/api/notes?limit=100&offset=0'

Returns 200 OK with {"notes": [...], "total": 12}. The default and maximum limit is 100; use offset to fetch subsequent pages. Order is creation date descending, then ID descending. Highlighting never changes the date or order. Times are UTC; the website displays them in your browser’s timezone.

Highlight a note

curl -X PATCH http://rmpizero2w.local/api/notes/1 \
  -H 'Content-Type: application/json' \
  -d '{"highlighted":true}'

Returns 200 OK with the updated note. Send false to remove the highlight. Note text is immutable; there is no edit endpoint.

Delete a note

curl -X DELETE http://rmpizero2w.local/api/notes/1

Returns 204 No Content. Deletion is permanent.

Errors & limits

Errors use {"error":"A readable explanation."}. Status codes: 400 invalid input, 403 cross-origin write, 404 missing note or route, 413 body larger than 100,000 bytes, 415 incorrect content type, 503 storage unavailable. POST and PATCH require Content-Type: application/json. Health check: GET /api/health.
